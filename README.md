# colored-squares
A browser program for viewing changing colored squares

This is pretty simple. The single source-code file of this repo (nineSquares.html)
allows users to generate colored squares randomly. Press Enter to distribute blue,
gold, or red squares (there will always be three of each) at randome in a 3 x 3
grid. Or press the space bar to reduced the randomness by keeping the same colors
in the same rows or columns on alternate turns.

It is hoped that users will find some light relaxation and amusement with this app.
